# Naming research

Research date: 2026-10-20. Availability checks are observations, not trademark clearance.

Chosen name: **TT Font Studio**, repository `tt-font-studio`.

The name describes a font-editing workspace for TT Games, leaves room for later engine formats, and avoids implying affiliation with another community project. A GitHub repository search for the exact candidate returned no existing project at the time of research.

Related projects:

- [OpenSaga](https://github.com/opensagadev) preserves and modernizes LEGO Star Wars: The Complete Saga. The name is already associated with that effort; reusing it would suggest a relationship.
- [TTG Font Creator](https://github.com/slankka/TTG-Font-Creator) edits **Telltale Games** fonts. TTG abbreviations can confuse the two engines, so the description explicitly says LEGO TT Games.
- [TTGames Explorer Rebirth](https://github.com/AcK77/TTGames-Explorer-Rebirth) uses the engine name with a specific tool role. TT Font Studio follows that descriptive naming pattern without claiming the explorer's scope.

Alternatives considered: `lego-font-editor` is discoverable but overly tied to a trademark; `tt-fnt-editor` is precise but less readable; `StudType` is more distinctive but says less about compatibility. GitHub search is not evidence that no similarly named tool exists elsewhere.
